# Automotive Detailing Business Dashboard

## Overview
Interactive Power BI dashboard analyzing sales data for Always Dry, 
an automotive detailing business in New Delhi.

## Tools Used
- Python (Pandas, NumPy) — dataset generation
- Power BI Desktop — dashboard and visualizations
- DAX — calculated measures

## Key Insights
- Total Revenue: ₹1.96 Crore across 2 years
- Glossy PPF = 51.7% of total revenue
- 58.63% repeat customer rate
- 800 transactions analyzed

## Dashboard Pages
1. Revenue Overview — KPIs, monthly trend, quarterly breakdown
2. Service Analysis — service comparison, customer type, payment methods
3. Customer Analysis — satisfaction scores, booking trends, repeat rate
